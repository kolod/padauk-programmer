## PADAUK datasheets

The datasheets are the property of PADAUK Technology and are not included in the repository
(`docs/*.pdf` is in `.gitignore`). Download them from the manufacturer's site
<http://www.padauk.com.tw/en/> and put them in this directory:

- `PFS154 datasheet_EN_V107_20240912.pdf`
- `PFC154 datasheet_EN_V004_20240905.pdf`
- `PADAUK_Package Information_V015.pdf`
